# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a Python learning repository for the **Copilot Express** course series. It covers Python fundamentals through data science, progressing from basic syntax to NumPy/Pandas/Matplotlib and a RAG/ML example.

## Running Code

```bash
# Run any standalone lesson script
python Lession1.py
python Dictionary1.py

# Launch the main interactive notebook
jupyter notebook chapter2.ipynb

# Open a specific notebook in VS Code
code chapter2.ipynb
```

There is no build step, test suite, or package installation file. Dependencies must be installed manually:

```bash
pip install pandas numpy matplotlib seaborn chromadb qrcode tabulate
```

Python 3.7+ is required.

## Repository Structure

All files live flat in the root directory. The naming conventions indicate topic and sequence:

| Pattern | Topic |
|---|---|
| `Lession1.py`, `Lesson2-*.py` | Python fundamentals (variables, conditionals) |
| `loops-*.py`, `Function-1.py` | Control flow and functions |
| `Listdatatype*.py`, `SetDS-1.py`, `Dictionary1.py` | Core data structures |
| `Classlecture1–6.py`, `Class4.py` | OOP progression (classes → inheritance → static methods) |
| `PandasLecture1–6.py`, `Pandastest*.py` | Pandas DataFrames, CSV/JSON I/O |
| `numpytest1–6.py`, `broadcastingnumpy.py` | NumPy arrays, reshaping, broadcasting |
| `Matplotlib1–5.py`, `Visualization1.py` | Matplotlib plotting (line, bar, pie, scatter) |
| `*Prj.py`, `*Project.py`, `*Game.py` | Standalone mini-projects |
| `*.csv`, `*.json`, `*.xlsx` | Data files used by Pandas/project scripts |
| `*.png` | Plot output files generated by Matplotlib scripts |

## Key Files

- [chapter2.ipynb](chapter2.ipynb) — Primary interactive lesson covering all four data structures (Lists, Tuples, Dictionaries, Sets) with exercises.
- [magic8_lesson__Control_flow_project.ipynb](magic8_lesson__Control_flow_project.ipynb) — Control flow project notebook.
- [Matplotlib_NeflixPrj.py](Matplotlib_NeflixPrj.py) — Capstone-style project: loads `Netflix_DataSet.csv`, generates bar charts, histograms, and scatter plots saved as `.png` files.
- [ModelComp-1.py](ModelComp-1.py) — RAG/ML example using ChromaDB for vector embeddings and SOP retrieval; the most advanced file in the repo.
- [CapstoneProject.py](CapstoneProject.py) — Journal entry reconciliation using Pandas.

## Conventions

- Scripts are standalone and executable independently — each imports only what it needs.
- Interactive scripts (games, calculators) use `input()` for user prompts; they are not automatable without mocking stdin.
- Matplotlib scripts call `plt.show()` to display plots interactively and `plt.savefig()` to write PNG files to the root directory.
- There are no shared utility modules; common logic is duplicated across files intentionally for learning clarity.
